# 🏪 CaféConnect - Sistema de Gestión de Cafeterías

Sistema integral para cafeterías con control de inventario, punto de venta (POS), ventas y programa de fidelización.

## 📋 Características

✅ **Punto de Venta (POS)** - Interfaz rápida para cobrar
✅ **Gestión de Inventario** - Control de stock por sucursal
✅ **Programa de Fidelización** - Puntos y canjes para clientes
✅ **Reportes** - Ventas, productos populares, análisis
✅ **Sistema de Login** - Control de acceso

## 🛠️ Tecnologías

- **Lenguaje:** Visual Basic .NET
- **IDE:** Visual Studio 2012+
- **.NET Framework:** 4.0 o superior
- **Base de Datos:** SQL Server (opcional)

## 📁 Estructura del Proyecto

```
CafeConnect/
├── frmLogin.vb              # Formulario de autenticación
├── frmPOS.vb                # Punto de Venta
├── frmInventario.vb         # Gestión de inventario
├── frmClientes.vb           # Gestión de clientes y puntos
├── frmReportes.vb           # Reportes y gráficos
├── Conexion.vb              # Clase de conexión a BD
└── README.md                # Este archivo
```

## 🚀 Instalación

1. Descarga el proyecto desde GitHub
2. Abre `CafeConnect.sln` en Visual Studio 2012
3. Compila el proyecto (Build → Build Solution)
4. Ejecuta la aplicación (F5)

## 📖 Uso
